이번 세션에서 한 작업의 로그를 `ai/journal/` 에 남긴다.

## 절차

1. `ai/journal/index.md` 에서 마지막 `AIJ-####` 번호를 확인하고 +1 한다
2. `ai/journal/TEMPLATE.md` 를 읽는다
3. `ai/journal/YYYY/MM/AIJ-####-<영문-슬러그>.md` 로 작성한다
   (연·월은 오늘 날짜, 슬러그는 소문자 kebab-case 3~6단어)
4. `git log --oneline` 으로 이번 세션 커밋 해시를 확인해 프론트매터에 넣는다
5. `ai/journal/index.md` 표 **맨 위**에 한 줄을 추가한다
6. `confidence: low` 이면 index 의 "확신이 낮은 판단" 절에도 추가한다
7. 검증하지 못한 가정이 있으면 index 의 "검증하지 못한 가정" 표에 추가한다

## 작성 지침

**세 절이 핵심이다. 나머지는 짧아도 된다.**

| 절 | 요구 |
|---|---|
| **왜 (근거)** | 관측한 사실·계산·문서상 제약을 인용한다. "~해 보여서"가 아니라 "~이므로" |
| **고려했으나 택하지 않은 것** | 대안마다 **버린 이유**를 쓴다. 이유 없는 나열은 적지 않은 것과 같다 |
| **확신이 낮은 부분** | 검증하지 못한 가정, 이 판단이 틀렸다면 어디서 먼저 드러날지 |

`confidence` 를 정직하게 쓴다. **낮은 확신을 높다고 적는 것이 유일한 잘못이다.**
`low` 로 표시된 엔트리는 관련 사고가 났을 때 가장 먼저 확인하는 곳이 된다.

ADR급 결정(되돌리려면 설계 회의가 필요한 것)이 나왔으면
`plan/90-decisions.md` 로 승격하고 프론트매터에 `promoted-to:` 를 남긴다.
